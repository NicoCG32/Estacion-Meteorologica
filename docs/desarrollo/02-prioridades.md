# 02 · Prioridades y próximos pasos

La prioridad es reproducir el montaje, conocer sus límites y conservar series útiles durante una operación prolongada.

| Prioridad | Trabajo                                                                      | Objetivo                                                          |
| --------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Alta      | Repetir el montaje y comparar sensores con instrumentos de referencia.       | Medir estabilidad, dispersión y deriva.                           |
| Alta      | Revisar alimentación, protecciones y configuración de red.                   | Preparar una operación segura y restringir el acceso al servidor. |
| Alta      | Probar cortes de red, reinicios, respaldos y recuperación del JSONL.         | Cuantificar pérdidas de muestras y conservar el historial.        |
| Media     | Revisar descartes, ausencia de datos y trazabilidad temporal.                | Mejorar la interpretación y reproducibilidad de las series.       |
| Media     | Preparar un montaje educativo reproducible.                                  | Facilitar talleres y uso en otros laboratorios.                   |
| Futura    | Incorporar identidad de estación si se conectan varios dispositivos.         | Distinguir el origen de cada medición.                            |
| Futura    | Evaluar medición de partículas, alimentación solar, carcasa y acceso remoto. | Ampliar el alcance con diseño y ensayos específicos.              |

Para adaptar la estación a otro ambiente habrá que revisar sensores, ubicación, protección y frecuencia de adquisición. Una instalación o servicio se presupuestará con una lista de materiales, mediciones de consumo, dedicación y alcance definidos.
